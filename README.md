# SDN Andonosari 1 — School Profile Website

## About the Project

A school profile website developed as part of the **Education Work Program for KKN-P 20 UMSIDA** and an implementation of **Appropriate Technology (Teknologi Tepat Guna / TTG)** to support the digital presence of rural educational institutions.

The website provides a centralized platform for accessing school information, managing educational content, and documenting academic and extracurricular activities. It was developed within a **one-week deadline**, addressing technical challenges while considering accessibility in areas with limited internet infrastructure.

## Key Features

- **School Information Portal** — Provides general information about the school.
- **Article Management** — Create, read, update, and delete articles.
- **Category Management** — Organize articles by category.
- **Teacher Management** — Manage teacher records and information.
- **Student Management** — Maintain student records.
- **Extracurricular Management** — Manage extracurricular activity information.
- **Account Management** — Manage administrative user accounts.
- **Guestbook** — Allows visitors to leave messages.
- **News and Announcements** — Publishes school updates and activities.
- **Content Management System (CMS)** — Simplifies website content administration.

## Technologies

The website was built using PHP, MySQL, HTML, CSS, and JavaScript.

## Development Highlights

- Designed and developed a school profile website tailored to the institution's informational needs.
- Integrated a CMS to simplify content updates and administrative tasks.
- Implemented database management for teacher and student records.
- Developed a user-friendly interface for accessing school information.
- Considered website accessibility in an area with limited internet infrastructure.
- Completed the project within a one-week development timeline.
