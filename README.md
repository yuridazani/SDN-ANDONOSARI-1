# Web Profil Sekolah SDN Andonosari 1

## Tentang Projek

Aplikasi ini dibuat untuk keperluan **Program Kerja bidang Pendidikan KKN-P 20 UMSIDA**. Website ini merupakan profil resmi **SDN Andonosari 1**, yang berisi informasi mengenai sekolah, data guru, siswa, serta berbagai kegiatan akademik dan non-akademik.

## Fitur Aplikasi

Aplikasi ini memiliki fitur-fitur dasar yang sederhana, antara lain:

1. **CRUD Artikel** (Create, Read, Update, Delete)
2. **CRUD Kategori Artikel**
3. **CRUD Data Guru**
4. **CRUD Data Jurusan**
5. **CRUD Data Siswa**
6. **CRUD Data Ekskul**
7. **Manajemen Akun**
8. **Buku Tamu**
9. Dan lain-lain
